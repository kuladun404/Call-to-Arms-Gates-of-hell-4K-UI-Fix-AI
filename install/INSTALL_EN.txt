=====================================================================
  Call to Arms Gates of hell - 4K UI Fix (AI)
  Installation guide (v1.0)
=====================================================================

WHAT THE MOD DOES
-----------------
On a 4K monitor (3840x2160) the game's interface is tiny. With this mod
the game believes it runs at 1920x1080 while everything is actually
rendered at full 4K. As a result:

  * the whole interface (menus, lobby, battle, settings) is exactly
    2x larger, like on a 1080p monitor, with no overlaps or cut text;
  * the 3D scene, water, shadows and effects are rendered at true 4K;
  * all interface fonts are replaced with sharp ones: every letter is
    redrawn as a vector outline at 4K, at exactly the original size;
  * the startup splash, the mouse cursor and the Steam overlay have
    the correct size.

The mod does not modify any game files: it is one d3d11.dll, a settings
file and a font folder next to the exe. Removing it is just as easy.


REQUIREMENTS
------------
  * A 3840x2160 monitor, set to that resolution in Windows.
  * Call to Arms - Gates of Hell (Steam), 64-bit.
  * A DirectX 11 graphics card.


PACKAGE CONTENTS
----------------
  d3d11.dll      - the mod
  ui4k.ini       - mod settings
  ui4k_fonts\    - sharp fonts (110 .raw / .pat files)

These three items are all you copy into the game.


INSTALLATION
------------
IMPORTANT: the game must be closed.

1. Open the game folder. In Steam: right-click the game ->
   Manage -> Browse local files. Then open:  binaries\x64
   (the folder with call_to_arms.exe)

2. Copy into that folder:
     d3d11.dll
     ui4k.ini
     the whole ui4k_fonts folder
   If an older ui4k_fonts folder is already there, delete it first.
   Do not touch or delete any other files in binaries\x64.

3. Start the game and set in the graphics options:
     Resolution:  1920x1080
     Mode:        fullscreen
   Restart the game if asked.
   (The mod turns 1920x1080 into real 3840x2160 - do NOT choose
   3840x2160 in the game.)

4. If you used the "ui_4k_scale" resource mod (enlarged fonts) before,
   disable it in the game's mod menu - it is no longer needed.

Done. The startup splash should be large and centred, and the
interface the same size as on a 1080p monitor.


HOW TO CHECK THAT IT WORKS
--------------------------
  * After the first start a ui4k.log file appears next to d3d11.dll -
    the mod's log. Lines "replaced" and "patched by" mean the sharp
    fonts were picked up.
  * The interface is large and sharp, the 3D scene fills the screen.


UNINSTALL
---------
1. Close the game.
2. Delete from binaries\x64:
     d3d11.dll
     ui4k.ini
     ui4k.log
     the ui4k_fonts folder
3. Start the game and set the resolution back to 3840x2160.


SETTINGS (ui4k.ini)
-------------------
Open it with Notepad. Main options:

  enabled=1      1 - mod on, 0 - completely off (game as without the mod)
  scale=2        scale factor (2 for 4K)
  font_hd=1      1 - sharp fonts from ui4k_fonts, 0 - stock (blurry) fonts
  font_big=1     1 - also the largest font pages (Cyrillic/Latin of the
                 main font); 0 - saves video memory (32 MB per page)
  log=1          1 - write ui4k.log, 0 - no log

Leave the other options (scale_ui_rt, cb_fix, ...) as they are - they
keep effects and shadows correct.


FAQ
---
Q: After a game update the fonts are blurry again.
A: The mod recognises font pages by their contents. If the developers
   change the fonts, the mod falls back to the stock (upscaled) fonts -
   the game still works. A new ui4k_fonts build is needed
   (tools/make_fonts.py, see README).

Q: Can I play online?
A: The mod does not touch the exe or the files the game checks in
   multiplayer (settings, maps, models). It has not been officially
   verified, though - use at your own discretion.

Q: The game does not start / black screen.
A: Delete d3d11.dll (or set enabled=0 in ui4k.ini) and test the game
   without the mod. The ui4k.log file shows what went wrong.

Q: The interface is still small.
A: Make sure the game is set to 1920x1080, not 3840x2160, and that the
   files are in binaries\x64 next to call_to_arms.exe.
