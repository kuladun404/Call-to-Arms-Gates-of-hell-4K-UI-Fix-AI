# Call to Arms Gates of hell - 4K UI Fix (AI) 2.0 — устройство

Прокси `d3d11.dll` для Call to Arms – Gates of Hell: интерфейс ×1…×2 на любом мониторе, мир в своём разрешении.

## Как пользоваться
В игре: «Параметры» → «Видео» → «Разрешение». Строки вида `2560×1440  ×2` — это «разрешение мира × масштаб интерфейса»;
монитор всегда остаётся в родном разрешении. Выбрать строку и нажать «Применить» — меняется и мир, и интерфейс.
Файлы игры и моды не трогаются; подписи строк DLL кладёт рядом с собой (`ui4k_labels.pak`). Настройки — `ui4k.ini`.

```
python build.py              # out\d3d11.dll
python build.py --test       # тесты без игры (WARP)
python build.py --install    # в игру (игра закрыта; бэкап в binaries\x64\ui4k_backup)
python build.py --uninstall  # откат: файлы мода + режим профиля, которого нет у монитора
python build.py --package    # архив для игроков out\package\GoH-UI4K-<версия>.zip: binaries\x64\d3d11.dll + ui4k.ini
                             # и package\README_RU.txt / README_EN.txt; никаких программ — ставится копированием
```
Нужен Python 3.11+ с пакетом `ziglang` (`pip install ziglang`); компилятор C ставить не нужно.

## Устройство
| Файл | Что делает |
|---|---|
| `src/proxy.c`, `log.c`, `vt.c`, `iat.c` | F02 загрузка, проброс экспортов, лог, патч vtable и импорта |
| `src/scale.c/.h`, `config.c` | F01 дробный масштаб, округление, `ui4k.ini` |
| `src/screen.c`, `swapchain.c` | F04 swapchain в физическом размере, игре — логический |
| `src/classify.c`, `resources.c` | F05 какие текстуры физические; коэффициент на ресурс |
| `src/ctx.c`, `device.c` | F06 обёртки immediate/deferred контекстов |
| `src/viewport.c` | F07 viewport и scissor |
| `src/cb.c`, `cbfix.c` | F08 экранные константы в CB |
| `src/copy.c` | F09 копии и сведение выборок между ресурсами разного настоящего размера: в D3D уходит только верный вызов |
| `src/upload.c`, `fmt.c/.h` | пиксели, которые игра загружает процессором в увеличенную текстуру; форматы и пересчёт картинки |
| `src/profile.c/.h` | настройки из профиля игры (HDR, MSAA), только чтение. С MSAA мир остаётся в размере строки (своя цель мира многовыборочная, `world.c`); безопасный режим — запасной ключ `msaa_safe=1` |
| `src/dpi.c` | процесс объявляется понимающим DPI (масштаб Windows не 100%) |
| `src/input.c` | F10 мышь и окна в логических координатах |
| `src/cursor.c`, `overlay.c` | F11 курсор, заставка, оверлей Steam |
| `src/modes.c` | F03 режимы экрана; L8 строки «мир × масштаб» |
| `src/loc.c` | L8 подписи строк (свой пакет перевода без мода) |
| `src/draw.c`, `world.c` | F14 мир отдельно от интерфейса (и без HDR) |
| `src/lum.c`, `lum_*.hlsl` | автоэкспозиция по всей картинке мира |
| `src/dof.c`, `dxbc.c` | Г4 радиус размытия глубины резкости; шейдер узнаётся по имени переменной в его отражении |
| `src/gamedata.c`, `anchors.c` | устойчивость к обновлениям игры: архив шейдеров игры (только чтение) — шейдеры по именам, размер буфера сцены, буферы HBAO+; `lum.c` пересобирает автоэкспозицию из исходника игры |
| `src/diag.c` | разведка: снимок кадра (`diag=1`, Ctrl+F11) |
| `build.py`, `tests/` | сборка, F12 установка/откат, F13 тесты |
